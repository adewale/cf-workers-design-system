# Product Pages

## Structure

```text
Hero
Benefits strip
How it works
Use cases
Architecture visual
CTA
Footer
```

## Composition Rules

- section rhythm should come from a parent gap system
- large wrappers get the border and corner decorations
- feature cards inside a strip do not each need their own loud framing
- use centered section intros with large medium-weight headings

## CTA Rules

- orange background is acceptable here
- primary button becomes white/cream on orange
- secondary action stays pill-shaped and lower contrast

## Footer Rules

- wide layout
- grouped columns
- soft cream layering rather than stark contrast
