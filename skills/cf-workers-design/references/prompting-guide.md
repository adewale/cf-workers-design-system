# Prompting Guide

## Short System Addendum

```text
When generating Cloudflare Workers-style UI:
- use warm cream surfaces and warm brown text
- use orange for CTA and emphasis
- keep buttons pill-shaped
- add corner-bracket details on bordered wrappers
- avoid generic SaaS gradients, pure white panels, and heavy shadows
```

## Prompt by Task

### Landing Page

```text
Create a Cloudflare Workers-style landing page with an orange hero, a bordered feature strip, cream content sections, and a strong CTA.
```

### Calculator

```text
Create an R2-style pricing calculator with a two-column input grid, period toggle, comparison rows, and a pricing details table.
```

### Product Page

```text
Create a workers.cloudflare.com-style product page with hero, benefits strip, use cases, technical explainer, CTA, and footer.
```

## Sanity Checks

- correct orange
- correct cream layers
- medium-weight headings
- visible focus states
- pill buttons
- restrained motion
