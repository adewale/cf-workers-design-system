# Templates

Starting-point structures for common page types.

## Landing Page

```text
Header
Hero
Feature strip
Stats or proof
Use cases
CTA
Footer
```

Implementation notes:

- Hero can be orange-on-light text.
- The rest of the page should return to cream surfaces.
- Use one bordered wrapper for the feature strip.
- CTA near the end can reuse the elevated orange container pattern.

## Pricing Calculator

```text
Header
Intro copy
Calculator shell
  Input grid
  Toggle group
  Comparison rows
  Use-case presets
Pricing details table
Footer
```

Implementation notes:

- Inputs are right-aligned.
- Unit selectors use a softer cream fill than text inputs.
- Comparison bars should make Cloudflare visibly favorable when the math supports it.

## Documentation Page

```text
Sticky header
Sidebar nav
Scrollable content
Back-to-top affordance
```

Implementation notes:

- Use dashed dividers between major sections.
- Sidebar links can use orange-light active states.
- Code blocks should use a dark brown-black base, not generic charcoal.

## Interactive Configurator

```text
Header
Two-panel body
  Controls panel
  Preview panel
Summary or CTA
```

Implementation notes:

- Keep form controls practical.
- Use mono in the preview or generated config output.
- Prefer direct labels over marketing copy.

## Dashboard or Metrics View

```text
Header
Stat cards
Comparison panels
Data table
Actions
```

Implementation notes:

- Product category colors can appear in badges and icons.
- Data density can increase, but the palette should remain warm.
- Use orange for action, category colors for taxonomy.
